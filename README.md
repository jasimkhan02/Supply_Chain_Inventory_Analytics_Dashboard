# Supply Chain & Inventory Analytics Dashboard

## 📌 Project Overview
This Power BI project provides an interactive analytics solution designed to monitor inventory health, optimize stock replenishment, and manage supply chain risks. The dashboard enables business stakeholders to make data-driven decisions to reduce stockouts and streamline supplier performance.

---

## 🔑 Key Features & Insights
* **Inventory Stock Breakdown:** Monitored total stock value and tracked critical low-stock alerts to streamline reorder quantities[span_0](start_span)[span_0](end_span).
* **Lead Time Risk Analysis:** Evaluated lead time variations across suppliers to identify fulfillment delays and supply chain bottlenecks[span_1](start_span)[span_1](end_span).
* **Root Cause Diagnostics:** Implemented Decomposition Trees to analyze the underlying drivers behind inventory delays and stock levels[span_2](start_span)[span_2](end_span).
* **Supplier Performance:** Analyzed order quantities, stock metrics, and heatmaps for comprehensive supplier evaluation[span_3](start_span)[span_3](end_span).
* **Dynamic Slicing:** Designed custom filters for Stock Status, Lead Time Risk, and Suppliers for exploratory analysis[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
